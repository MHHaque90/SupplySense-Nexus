`console.log` and basic styles). They were moved here during Phase 12B when
`frontend/` became a React + Vite + TypeScript application; Vite requires
`frontend/index.html` as its entry point.

Nothing imports or serves these files. They are kept for history only and can
be deleted in a later cleanup phase.
